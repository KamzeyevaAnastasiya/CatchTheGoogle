Catch The Google 🎮

Catch The Google is a browser-based multiplayer game where two players compete to catch the moving Google icon and score points. The game uses a WebSocket server for real-time synchronization between the client and the game logic.

🚀 Play the Game

Note: The backend is hosted on Render using the free plan. If the server has been inactive for a while, it may take up to 50 seconds to wake up before the game starts. Please wait a moment and refresh the page if necessary.

⸻

🎯 How to Play

1. Open the game using the link above.
2. Configure the game settings if desired.
3. Click Start Game.
4. Catch the moving Google icon before your opponent.
5. The player with the highest score at the end of the game wins.

Controls

Player 1

* ⬆️ Up
* ⬇️ Down
* ⬅️ Left
* ➡️ Right

Player 2

* W – Up
* S – Down
* A – Left
* D – Right

💻 Run Locally

Install dependencies:

pnpm install

Start the WebSocket server:

pnpm start

Open the frontend

Open index.html using your preferred local web server (for example, Live Server in VS Code or the built-in server in WebStorm).

⸻

🌐 Deployment

* Frontend: GitHub Pages
* Backend: Render

The frontend automatically connects to the WebSocket server running on Render.
